## 5. Determine Severity

Use the severity matrix:

| Level | Criteria | Response Time |
|-------|----------|---------------|
| Critical | Production down, data loss, security breach | < 1hr |
| High | Major feature broken, no workaround | < 4hr |
| Medium | Feature impaired, workaround exists | < 24hr |
| Low | Cosmetic, minor inconvenience | < 72hr |
